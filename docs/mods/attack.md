# Amp Attack

Model:Samples only. The Amp **Attack** the Model:Samples doesn't have: from instant
(as stock) up to a one-second fade-in, for pads, swells and softened hits.

![FUNC + DECAY: Amp Attack](media/attack-func-decay.png)

- Hold **FUNC** and turn **DECAY**: the attack of the active track, one value a step,
  0 (instant) to 127 (1 s).
- Like the other sound parameters it can be **p-locked** (hold a trig, then FUNC +
  DECAY), it is an **LFO destination**, and it is saved with the sound and the
  project.

## Good to know

- Back on the stock firmware a project loses its attack, an attack p-lock turns into a
  lock of another parameter, and an LFO set to attack points elsewhere: clear them
  before going back to stock.
- In a p-lock the knob moves slowly (about +5 per 30 clicks): its step curve is
  borrowed from Filter Resonance.
